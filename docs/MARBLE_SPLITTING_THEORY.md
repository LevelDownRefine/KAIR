# MARBLE：先证明训练拆分，再进行实验

## 理论入口与结论范围

本轮针对用户“先理论尝试，包括类似 ADMM 的拆分，找到基本可证明的再跑实验”的要求。
目标是证明**所有参与优化的参数与辅助表征的训练迭代**，而非仅证明冻结网络后的推理。
本文在实现与真实数据实验前单独提交，作为理论门槛；它不是同行评审或形式化证明。

筛选结果：采用同一目标上的同步近端梯度（joint PFB）和交替近端梯度（PALM）。
在下述明确模型、精确算术及精确投影下，可建立充分下降、相对误差、有界性与 KL 条件，
因此整个训练序列收敛到约束临界点。结论不是全局最优、行为指标提升或原 MARBLE 的等价复现。

## 1. 拆分方法逐项筛选

| 方法 | 对当前问题缺少什么 | 本轮决策 |
| --- | --- | --- |
| 原始非线性 ADMM，V = Zθ | 不能用凸 ADMM 定理；固定几步 Adam 不保证子问题误差趋零，也未建立增广拉格朗日下降 | 不将原实现认定为有训练收敛证明 |
| 非凸线性化 ADMM / 近端 ALM | 有适用研究，但需落实非线性约束的正则性、惩罚参数、误差控制和有界性 | 保留方向；本轮不以“名称相似”套用定理 |
| Douglas–Rachford / Peaceman–Rachford | 通常要求光滑项曲率界和可控的全局近端子问题；编码器近端本身仍是困难的非凸优化 | 不将有限 Adam 内循环当作近端解 |
| PnP / 伪压缩不动点法 | 已有隐式层固定权重时的收敛证明，但不能推出学习权重的更新收敛或 MAP 等价 | 保留上一轮结论，不替代本轮训练证明 |
| 固定罚参数 HQS，精确交替最小化 | V 块可解，但精确 θ 块仍难；仅增大罚参数不能自动恢复原约束问题 | 以近端线性化替代难解的 θ 块 |
| PALM / 近端交替线性化 | 要求光滑耦合、可计算分离近端、步长控制、有界性及 KL 性质 | 通过下述网络和约束显式满足 |
| 同步 PFB / 近端梯度 | 同一乘积空间上的近端可分解；用共同回溯控制耦合项 | 作为同目标、同结构的求解器对照 |

理论来源：[经典 ADMM](https://web.stanford.edu/~boyd/papers/admm_distr_stats.html)、
[非凸 DRS/ADMM](https://arxiv.org/abs/1709.05747)、
[非线性约束的非精确线性化 ADMM](https://arxiv.org/abs/2503.01060)、
[PALM](https://bolte.perso.math.cnrs.fr/BST2013.pdf)、
[充分下降与 KL 框架](https://bolte.perso.math.cnrs.fr/MPA.pdf)。
表格是对我们具体模型的适用性判断，不是否定这些方法在其他条件下的收敛性。

## 2. 明确修改后的模型

固定训练神经数据、原编码器锚点 Q、正负样本对及图拉普拉斯 L，满足
L = Lᵀ、0 ⪯ L ⪯ 2I。只训练新残差网络及辅助变量 V。

```text
Uθ(Q) = Q + W2 tanh(W1 Q + b1) + b2       （按样本逐行计算）
Zθ(Q)i = Uθ(Q)i / sqrt(||Uθ(Q)i||² + ε²),   ε > 0
```

θ = (W1, b1, W2, b2) 属于紧凸集合 C：每个矩阵的谱范数不超过 1，
每个偏置向量的欧氏范数不超过 1。软归一化处处光滑且每行范数小于 1。
这不是原来的 ReLU + 截断单位归一化，也不是上一轮有限展开隐式网络。

定义（范数默认 Frobenius / 参数欧氏范数）：

```text
f(θ) = β ||θ||²/(2P) + δC(θ),             β > 0
Hλ(θ,V) = ℓ(Zθ) + λ tr(VᵀLV)/(2n) + η ||V-Zθ||²/(2n),   η > 0
Fλ(θ,V) = f(θ) + Hλ(θ,V).
```

ℓ 为固定有限正负样本的 logistic 对比损失；δC 在 C 上为 0，其他地方为 +∞。
λ ≥ 0、η、β 和图/样本对在一个训练运行内固定。

**目标变化必须明示。** 这里的 V 与 Zθ 采用有限二次罚项，不是硬等式约束。
精确消去 V 得到

```text
V*(θ) = (ηI + λL)^(-1) η Zθ,
F̄λ(θ) = ℓ(Zθ) + f(θ) + tr(Zθᵀ K Zθ)/(2n),
K = η λ L (ηI + λL)^(-1).
```

K 在图特征值 μ 上的响应为 ηλμ/(η+λμ)，故它是原二次先验的平滑包络，
高频惩罚被限制到 η。同步与交替方法求解同一个 Fλ；不将 Fλ 与原未松弛目标混称。
因为 V 子问题强凸，Fλ 的任一约束驻点有 V=V*(θ)，并对应 F̄λ 的约束驻点。
η→∞ 时 K→λL，但本轮不把固定 η 的实验当作该极限。

## 3. 分离近端可以精确计算

对 t>0，

    prox_(t f)(A) = Projection_C(A / (1 + tβ/P)).

矩阵谱球的 Frobenius 最近点投影由 SVD 的奇异值截断得到：
若 A=U diag(σ) Vᵀ，则投影为 U diag(min(σ,1)) Vᵀ。
偏置投影为 a/max(1,||a||)。

这里必须使用奇异值逐个截断；上一轮统一缩放整张矩阵虽然能保证谱界，
一般并非最近点投影，不能直接用于此近端最优性证明。

## 4. 交替更新（PALM）

设 c=0.1，最大参数步长 tmax>0。每轮从 t=tmax 开始减半回溯：

```text
gθ = ∇θ Hλ(θk,Vk)
θ+ = prox_(t f)(θk - t gθ)
```

直到满足光滑上界检验

    Hλ(θ+,Vk) ≤ Hλ(θk,Vk) + <gθ, θ+-θk>
                   + (1-c)||θ+-θk||²/(2t).

然后令 s=n/(η+2λ+1)，作一次显式 V 更新：

    V+ = Vk - s [λ L Vk + η(Vk-Zθ+)]/n.

将图能量放入光滑 Hλ，V 块的分离非光滑项取 0，因此 V 更新是一个精确的
线性化子问题解，不需要假定有限 CG 已精确求解整个图近端。

## 5. 同步更新（同目标 PFB）

在 (θk,Vk) 同时计算两块 Hλ 梯度，设 t=ω tmax、s=ω n/(η+2λ+1)，
从 ω=1 开始减半，候选点为

```text
θ+ = prox_(t f)(θk - t ∇θHλ(θk,Vk))
V+ = Vk - s ∇VHλ(θk,Vk).
```

直到

    Hλ(θ+,V+) ≤ Hλ(θk,Vk) + <∇θHλ,Δθ> + <∇VHλ,ΔV>
                    + (1-c)/2 [||Δθ||²/t + ||ΔV||²/s].

这是固定块预条件度量乘以共同步长的近端梯度，投影与高斯近端仍精确可分解。

## 6. 证明主干

### 命题 A：迭代有界，局部光滑常数可统一

θ 始终在紧集 C。Fλ 各项非负，若下降则 η||V-Zθ||²/(2n)≤Fλ(θ0,V0)。
又每行 ||Zθ,i||≤1，所以 V 有界。所有迭代及连接它们的线段落在一个紧集内。
网络、logistic 损失和二次项处处解析，故其一阶导数在该紧集上 Lipschitz。
参数候选点经投影仍在 C；同步 V 候选点也由有界梯度和有界试探步长保持有界。
因此回溯有限终止，且被接受的步长有统一正下界和有限上界。

### 命题 B：充分下降

近端最优性与参数回溯检验相加，得到

    Fλ(θk,Vk)-Fλ(θ+,Vk) ≥ c||Δθ||²/(2t).

V 梯度的全局 Lipschitz 常数不超过 LV=(η+2λ)/n，且 s LV<1。
下降引理给出

    Fλ(θ+,Vk)-Fλ(θ+,V+) ≥ ||ΔV||²/(2s).

故 PALM 一轮至少下降上述两项之和。同步更新同理由联合回溯得到

    Fλ(xk)-Fλ(xk+1) ≥ c/2 [||Δθ||²/t + ||ΔV||²/s].

步长有界，故两者均满足 Fλ(xk)-Fλ(xk+1) ≥ a||xk+1-xk||²，a>0。
于是目标收敛且相邻迭代差趋零。只到这一步还不能声称整个序列收敛。

### 命题 C：相对误差与驻点

参数近端的最优性条件为

    -gθ - Δθ/t ∈ ∂f(θ+).

将其与新点的 ∇θHλ 相加，构造 ∂θFλ(θ+,V+) 中的元素。
新旧梯度的差由局部 Lipschitz 常数乘以步长差控制，1/t 又有上界。
V 更新同理给出 ∇VFλ(θ+,V+) 的上界。因此存在统一 b，使

    dist(0,∂Fλ(xk+1)) ≤ b ||xk+1-xk||.

同步算法以同样方式证明。聚点位于 C，Hλ 与高斯项连续，故聚点满足
0 ∈ ∂Fλ。这是包含谱球法锥的约束驻点，不能用未投影的梯度为零替代。

### 命题 D：KL 性质与整个序列收敛

谱球和偏置球是半代数集合。tanh、log/exp 与正数平方根构成的 Hλ 可定义于
包含指数函数的 o-minimal 结构；也可在有界邻域中利用解析性与半代数约束。
因此 Fλ 为适当下半连续 KL 函数。**含 logistic / tanh 的目标不应被误称为半代数。**
结合 A–C 及聚点处目标连续性，应用充分下降—相对误差—KL 框架，
得到有限路径长度 Σ||xk+1-xk||<∞，因而整个序列收敛到一个约束临界点。
这对应 PALM/PFB 文献的基本论证，不依赖网络训练问题凸。

## 7. 从定理到实现的门槛

真实数据实验开始前必须完成：

1. 独立解析例验证谱球最近点投影，而不只检验投影后谱范数。
2. 用凸二次参考问题验证两种更新的充分下降和相同解；用稠密消元核对 K。
3. 验证网络梯度、参数/辅助变量更新及保持谱约束。
4. 每次真实更新记录光滑上界检验与充分下降余量，并报告回溯次数。
5. 记录投影梯度映射与 V 的驻点残差；不能把达到预设迭代上限当作收敛。

实现使用 float64、小矩阵 SVD 和显式 V 步，不用隐藏的非凸内循环、有限 CG 或 Adam。
精确算术定理不等于浮点程序形式化验证：数值误差、约束可行性和下降偏差单独报告。
如果回溯无法接受更新，保留失败并停止，不靠放宽误差容限或换种子掩盖。

## 8. 未被证明的内容

- 全局最优、唯一解、摆脱所有鞍点或任意给定收敛速度。
- 原 MARBLE、上一轮隐式网络与当前模型的等价性。
- 有限轮训练已经到达驻点，或谱约束意味着整个网络伪压缩。
- 解码、一致性或跨动物泛化一定改善。

满足本文门槛后，才固定实验参数并评估行为指标；理论失败不能由较好分数弥补。
