# MARBLE 前置投影：状态与增量联合保真

Achilles 数据；用户未声明已逐项审阅本文。运行前固定方案：2026-09-29。

## 研究问题与主对照

同样从 120 维降到 20 维，在投影阶段保留更多神经活动增量，能否改善后续
MARBLE 表示的离线位置解码？只改变前置投影，不改变网络或引入行为监督。

列向量 r_t，训练均值 m，增量 s_t = r_(t+1) - r_t。U 为 D×q 正交基，
P = UUᵀ。令 A = Σ||(I-P)(r_t-m)||²，B = Σ||(I-P)s_t||²，
S = Σ(r_t-m)(r_t-m)ᵀ，D = Σs_ts_tᵀ。

最小化 A/tr(S) + αB/tr(D)，闭式全局解是 S/tr(S)+αD/tr(D) 的前 q 个
特征向量张成的子空间。相当于 λ = αtr(S)/tr(D) 的 A+λB。
α=0 为精确 PCA，α=1 为预先指定的主实验；α=0.1、10 为敏感性检查。
所有 α 都报告，不按测试集挑选参数。

相对于精确 PCA，正权重解满足训练 A 不减、B 不增：由 PCA 对 A 的最优性和
联合目标的最优性直接相减得到。该结论不保证测试误差或行为解码改善。
增量不再次中心化；仅用训练数据估计均值、能量和投影。为减少坐标方向干扰，
所有解用正交 Procrustes 在子空间内对齐到同一个精确 PCA 基，不做白化。

## 固定实验方案

- 同一只大鼠、同一次时间划分：前 8000 bins 训练，后 2000 bins 测试。
- 各段独立采用作者原始 GaussianKernel 平滑；保留原代码时间单位及非零 bin
  当事件的处理。对绝对生理时间的解释仍沿用此前复现限制。
- 每组 20 维状态与 20 维增量；图和梯度按原算法重算；编码器仍为 440→64→32。
- 种子 0、1、2，各 100 轮；SGD、批采样、训练图内验证选 checkpoint、余弦
  kNN(k=36) 解码均沿用既有协议。相同种子初始权重必须一致。
- 训练在既有 PyTorch 2.14.0+cu130 / RTX 5070 Ti 上完成；图与原始采样计划
  在既有原作者 CPU 环境中导出。
- 每组训练前核对原代码 3 步 SGD；训练后通过原代码回读全部 checkpoint。
- 主指标：冻结 BN 的时间留出 MAE（cm），另报 R²、各种子结果、训练/测试
  状态与增量投影残差。三种子标准差只描述训练随机性，不代表跨个体统计证据。
- 既有随机 PCA 基线只作历史参考；本轮主比较用重新训练的精确 PCA。
- 测试窗口整体构图，因此属于离线解码；不宣称在线预测或跨个体改进。
