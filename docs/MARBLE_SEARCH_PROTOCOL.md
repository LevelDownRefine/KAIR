# 理论约束下的超参数搜索：固定方案

## Material Passport

- 2026-09-28；用户允许超参搜索后、搜索执行前制定。
- 目的：检查 RRR 的旧条件失败是否能通过有理论含义的超参改善。
- 数学基础：[有限维命题 A–D](MARBLE_MATH_FOUNDATIONS.md)。
- 这是有限预算的条件性内部验证，不是无限搜索或新的独立确认实验。

## 候选与不变项

条件数预算 `kappa ∈ {3,10,30,100,300}`，预测间隔
`lag ∈ {2,4,8,16,32}`，共 **25 组**。不搜索表示维数、decoder 或评估定义。
每组检查三个地标种子、Achilles rank 32 及四动物 rank 3，共 15 个任务。

每个训练前缀用特征协方差极值，按命题 D 的公式选择达到条件数预算的最小
ridge（加数值下限）。它限定求逆放大，不保证统计最优。延长 lag 改变预测
目标和谱，不保证谱间隙扩大。lag 至少为 2，避免一阶前向差分直接揭示下一
状态这一特定重叠；不把原有平滑数据宣称为严格因果或独立观测。

Gaussian 字典仍为 256 个地标，原有两块 RMS 归一化与带宽规则不改。
本轮字典只拟合于各任务神经序列的前 60%，然后冻结；不复用包含内部验证
窗口的旧字典。Achilles 只读取既有外部训练图的 7999 点，外部测试图不参与。
四动物采用原 9999 点序列。已有 PCA/平滑输入固定：内部验证没有重新从原始
spikes 拟合完整前处理，因此只评价这个固定输入空间中的子模块。

## 数据边界与理论筛选

训练段为 `[0, floor(0.6N))`；其后隔离 64 个点，其余作为内部验证。
所有时滞对分别在各段内部构造，不跨训练/验证边界。
训练段再分为两半，分别构造时滞对，排除跨半段的对。比较训练整体与各半段
的 `H=B Bᵀ`，字典及完整训练段选出的 ridge 均冻结。

继续采用相同形式的充分条件：**一组参数的全部 30 个比较都必须满足
`2 * ||H_half-H_train||₂ < gap_r(H_train)`** 才可进入后续行为指标试验。
这里的两个时间半段都是内部训练数据，验证段不用于这个证书。
证书只覆盖观察到的扰动；失败不证明算法必然不稳定，也不是总体置信界。

## 选择规则

在内部验证上计算未来核特征预测平方误差，以及对应 lag 的 persistence
预测（保持当前核特征不变）的平方误差。记录二者比值，避免直接把不同
预测时间间隔的原始误差当作相同难度。该归一化仍不是跨 lag 的等价性证明。

仅在通过全部理论比较的候选中，按 15 个任务的平均误差比最小选参；
完全相同则优先更短 lag，再优先更小条件数预算。验证结果不用于放宽证书。
若无候选通过，输出 `selected = null`，不计算新的位置 MAE 或动物一致性 R²。
结果保留全部 25 组，不只保留最佳组。零误差 persistence 情况显式报错。

此搜索不声称选定参数对新的动物/划分有效；若以后进入行为指标比较，仍需
新验证协议、静态字典/时间打乱消融，并报告既有外部留出集已经被观察过。
