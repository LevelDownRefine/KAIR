# 不冻结 MARBLE：训练收敛论证的扩展

本理论记录在实现与新一轮数据拟合之前提交。问题是：上一轮冻结原编码器，
是否属于证明必需的假设？答案是否定的。关键是整个可训练映射满足光滑性，
且所有优化变量有界、每块更新满足下降与相对误差条件。

## 1. 原实现的障碍与修改

本地 `models/network_marble.py` 为固定图特征 H、两层线性编码器、BatchNorm、
ReLU、可选 dropout 与 `F.normalize`。固定神经数据的图特征没有可训练参数。

- ReLU 以及截断范数归一化在部分点非光滑，不能直接放入上一轮的光滑耦合项 H。
  这不意味着不存在其他非光滑收敛理论，只是不能原封不动套用当前证明。
- 普通训练态 BN 的移动统计量会增加未被当前优化目标描述的状态更新。
- 每轮随机 dropout / 随机重采样也不能直接纳入本轮固定目标、精确梯度的证明。

因此作明确的数学模型修改：

1. 将原模型**推理态 BN** 精确吸收进首层仿射变换。设原线性层为 Wh+b，
   BN 为 gamma*(u-mu)/sqrt(var+eps_BN)+beta，则
   `A = diag(gamma/sqrt(var+eps_BN)) W`，
   `a = gamma*(b-mu)/sqrt(var+eps_BN)+beta`。
   之后 A、a 整体参与训练；不保留冻结的 BN 权重或移动统计量。
   这是原推理函数的精确重参数化，不是原训练态 BN 的等价动态。
2. 用训练特征固定计算 m 与逐列尺度 s，令 X=(H-m)/s；将 A 换为 A diag(s)，
   a 换为 a+A m。初始化函数保持不变，测试只使用训练统计量。
3. 用 `rho_delta(t)=(t+sqrt(t²+delta²))/2` 替代 ReLU，delta>0 固定。
   它处处解析、导数在 (0,1)，且与 ReLU 的误差不超过 delta/2。
4. 编码器和残差层输出均使用 `u/sqrt(||u||²+epsilon²)`，epsilon>0。
   不使用随机 dropout；图、样本对、数据标准化统计量固定。

最终全参数网络为：

```text
q_phi(X) = softnorm_epsilon(B rho_delta(A X+a)+b)
Z_phi,theta(X) = softnorm_epsilon(q_phi + W2 tanh(W1 q_phi+c1)+c2).
```

所有有效编码器参数 phi=(A,a,B,b) 和新增层参数 theta=(W1,c1,W2,c2) 均更新。
原未启用扩散模式的 `diffusion_time` 不影响函数，因此不作为虚假的可训练参数保留。
固定图特征及输入标准化是数据预处理，不能称为学习了图结构或原始神经信号生成模型。

## 2. 统一优化目标与可计算近端

记全部参数为 w=(phi,theta)，P 为全部参数数量。使用上一轮同形式的目标：

```text
F(w,V) = ell(Z_w) + lambda tr(V^T L V)/(2n)
       + eta ||V-Z_w||²/(2n) + beta ||w||²/(2P) + indicator_C(w).
```

约束 C 为有限个矩阵谱球和向量欧氏球的乘积。每个半径 R_j 是训练前固定的正数，
不要求都等于 1。可以选 `max(1,1.25*||w_j^0||)`，使原权重初始化在约束内部。
新增残差层继续用半径 1。基于初值确定的半径不参与优化，也不根据行为指标挑选。

分离近端仍为 `Projection_C(p/(1+t*beta/P))`。半径 R 的矩阵投影将每个奇异值
截断到 R；向量投影到半径 R 的欧氏球。原训练难题没有被移入隐藏的非凸子问题。

冻结对照只允许 theta 更新，相当于同一 F 在 phi=phi0 的仿射子空间上优化。
为了使它真正属于同目标对照，P 和高斯项定义仍使用全体参数，包含固定 phi 的常数项。
解冻组允许 phi 与 theta 同时更新；两组使用完全相同的修改后结构和初值。

## 3. 收敛命题与论证

条件：固定有限训练数据/图/样本对，0<=L<=2I，eta>0、beta>0，delta、epsilon>0，
有限固定约束半径；使用精确梯度、精确投影及回溯，按上一轮 PALM 更新 w、V。

结论：精确算术中，每个训练序列 (w_k,V_k) 有有限路径长度，并收敛到 F 的一个
约束临界点。**这一次 w 包含整个有效编码器**，不需要冻结 phi。

逐项检查如下：

1. C 紧，全部网络参数始终有界。Z 每行范数小于 1，非负目标的水平集与 eta>0
   保证 V 有界。整个优化序列及回溯候选点落在一个紧集内。
2. X 是固定有限矩阵；线性层、平滑正部、tanh、软归一化均解析。因此 H 的全梯度
   在相关紧集上 Lipschitz。编码器层数有限或维度增加，不破坏这一性质。
3. 参数回溯有限终止，接受步长有统一正下界。V 的梯度 Lipschitz 界仍为
   `(eta+2lambda)/n`，所以 `s=n/(eta+2lambda+1)` 的显式更新仍合法。
4. 与上一轮相同，由近端最优性及回溯上界得到
   `F_k-F_(k+1) >= c||delta_w||²/(2t_k) + ||delta_V||²/(2s)`。
   向全体 w 扩展不会改变这个推导。
5. 近端最优性加新旧梯度差，仍给出
   `dist(0,partial F_(k+1)) <= b||(delta_w,delta_V)||`，b 有限且统一。
6. 谱球约束半代数，平滑正部/软归一化半代数解析，tanh/logistic 可定义于含指数的
   o-minimal 结构；F 为 KL 函数。不能只因含 ReLU 就断言可用光滑 PALM，也不能
   把含 tanh/logistic 的完整 F 称为半代数。
7. 结合有界性、充分下降、相对误差和聚点处目标连续性，应用 KL 收敛框架，
   得到整个序列收敛。可直接沿用上一轮已验证的双块实现，将参数块扩为 w。

同样的变量扩展也适用于上一轮同步 PFB，但本轮实验只用 PALM 隔离“是否解冻”。
有限罚参数的图先验仍是 Moreau 平滑目标，未恢复硬等式 ADMM。

来源：[PALM](https://bolte.perso.math.cnrs.fr/BST2013.pdf)、
[充分下降与 KL 框架](https://bolte.perso.math.cnrs.fr/MPA.pdf)。
这是既有框架的适用性推导，不声称新定理、形式化验证或已通过同行评审。

## 4. 证明边界与实现门槛

- 保证的是修改后全参数网络的约束临界点；不是原 ReLU/BN/随机训练过程的定理。
- 不是全局最优、有限预算收敛、行为指标改善或跨动物泛化保证。
- 小幅结构变更也可能改变初始指标，所以必须同时保留原基线、未训练修改结构、
  同结构冻结对照，以及全参数有/无图先验组。
- 真实拟合前验证 BN/标准化折叠的函数与输入梯度对齐、全参数梯度、每个有效
  编码器张量确实被更新、冻结对照保持编码器不动、CPU/CUDA 对齐与每步充分下降。
- 保存完整参数变化量、可行性、驻点残差和所有种子。浮点诊断不能替代精确算术证明。
