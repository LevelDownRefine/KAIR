## 1. 目标与完成标准

目标是在官方 PyTorch CUDA 13、uv 锁定的 KAIR 环境中，从输入数据重建
MARBLE 的主要计算过程、训练模型、重算指标并生成对应图表。
需要分别回答两个问题：实现是否忠实于选定的原版协议；该协议能否支持论文结论。
算子数值接近不能单独证明科学结论已复现。

逐项标注证据等级，不用一个“已复现”覆盖不同工作量：

1. **作者产物重评估**：读取作者权重或表征，重算解码、距离及图表。
2. **MARBLE 从头训练**：从观测数据或作者提供的 RNN 轨迹开始，重新训练 MARBLE。
3. **端到端重建**：补齐原始脉冲预处理、任务 RNN 训练和主要学习型基线训练。

最终审计覆盖主图 2–5、Extended Data 1–9、Supplementary Figures 1–5。
Fig. 1 的方法示意通过算子和数据流核验，不把重画示意图计为数值复现。
逐个子图登记数据、协议、种子、训练来源、指标、图表和差异；只有完成声明范围内
的必要训练与比较，且没有未解释的主要结论冲突，才使用“完整复现”表述。
不能访问的输入、未重训的基线或无法确认的会话排除规则都保留为明确缺口。

来源：[论文与补充材料入口](https://www.nature.com/articles/s41592-024-02582-2)、
[官方代码](https://github.com/Dynamics-of-Neural-Systems-Lab/MARBLE)。

## 4. 分阶段实施

### P0：冻结实验登记表和输入

以数据清单、论文、notebook、检查点三方记录生成配置登记表；
保存源码提交、uv.lock、设备与驱动、预处理哈希、数据划分、种子和检查点来源。
历史参考实现固定上游提交 `09491ec077bf153b7dece8518cc65ddaa20eb26d`；
当前 CPU 导出器固定 MARBLE fork 提交 `872e46bd6dff2d092f8554a8c084701450e84904`。

验收：每个计划指标可追溯到一个明确协议，未指定项显式标注，作者模型和新训练模型不混用。

### P1：四只大鼠及跨动物一致性（优先）

1. 扩展导出器支持 Achilles、Buddy、Cicero、Gatsby，保存每只动物的划分与 PCA 状态。
2. 让编码器支持原版 dropout，先核验 3D 作者权重和 PCA=10；保留现有 Achilles 回归核验。
3. 按相应协议训练 3D 表征并计算 12 个有向动物对的一致性；32D 位置解码先对齐论文指定对象，
   其他动物解码作为扩展结果单列。
4. 对齐作者 CEBRA 的维度、数据、解码器和一致性拟合流程；分别输出作者权重评估与从头训练结果。
5. 按论文明确的比较关系核验结果；已确认作者检查点的 MARBLE 高于 CEBRA-time、
   低于 CEBRA-behaviour，BN/dropout 模式变化不改变这一排序。

验收：四动物、全部有向对及失败项均有记录；差异归因有逐项对照，不能只筛选表现好的种子。
建议训练先固定种子 0/1/2，与现有实验一致；这是工程重复性起点，不等于统计样本量已充足。

### P2：通用 CUDA 算子和合成动力系统

实现二阶梯度组合、可选位置拼接、向量/表征归一化、灵活 MLP/BN/dropout、
可学习内积特征，以及曲面所需局部切空间和平行移动。
核验多个条件图的节点偏移与批处理，不允许邻居跨越不相连的实验条件。

按小图算子、真实导出图、平面场、Van der Pol 的顺序推进。
对特征、损失、参数梯度及连续更新与原版作固定输入对照；
验证旋转/坐标变换后的不变量，而不要求随机训练出的潜空间坐标逐值相同。
Van der Pol 同时记录积分告警、被过滤轨迹和各条件采样数量。

验收：Fig. 2 的定性结构和预先登记的距离/聚类指标均能解释；
若分界仍不一致，保留反例及误差来源，不能用另一个采样设置掩盖。

### P3：RNN 的动力学与任务计算

先在作者轨迹上复现 aware/agnostic 两种 MARBLE 模式及 120 条件的距离结构，
再补任务表现、增益与分岔关系、多解比较及 CCA。
输出条件排序表，分开比较表征几何、距离矩阵和任务行为。
最后从头训练任务 RNN 并重复关键分析，区分“固定作者 RNN 上重训 MARBLE”
和“任务 RNN 加 MARBLE 的全链路训练”。

验收：距离相关接近只是其中一项；Fig. 3 的行为对应和对照也必须有独立输出。
新 RNN 解可有不同坐标与参数，不以权重逐值相同为标准。

### P4：可学习扩散与猕猴全部会话

实现原版标量/向量扩散所需谱与运输算子，并保留扩散时间的梯度。
当前 `GraphFeatures.__call__` 整体位于 `torch.no_grad()`：
可以缓存固定图几何，不能把依赖可学习扩散时间的输出整体缓存或断开梯度。
仅取消现有参数限制不足以支持此模型。

先用一个会话分别跑 3D 可视化和 20D 解码，核验前向、扩散参数梯度、优化与显存。
随后按已登记的会话清单逐场训练；5/10 折解码按试次隔离，明确表示学习阶段是否
使用整个会话，不能把解码器交叉验证解释成整个表示学习流程独立留出测试。
明确方向分类器训练数据及评估定义。再补原始脉冲到发放率的转换和基线训练。

验收：每场会话都有输入、训练、表征、解码和纳入记录；3D 与 20D 各有真实产物；
43/44 会话差异若仍未解决，必须保留为与论文汇总比较的限制。

### P5：扩展图、敏感性与独立重跑

建立 Extended Data 1–9 和 Supplementary Figures 1–5 的逐图覆盖表：
旋转与流场、变形流形、RNN 结构与不同解、猕猴 LFADS/TDR/PCA/t-SNE/UMAP，
以及局部坐标、梯度滤波、阶数和真实数据超参数敏感性。
先补与核心结论相关的实验，再执行预先登记的参数网格。
从干净结果目录做独立重复运行，审计检查点选择、输出完整性与关键结论。

验收：最终报告同时列出成功、部分一致、失败和未执行的子图；
有关键冲突或缺失时，结论保持“部分复现”。

## 5. 设备、资源与监控

当前训练环境为 uv 锁定的 Python 3.12、PyTorch 2.14.0+cu130、TorchVision 0.29.0+cu130。
本机 RTX 5070 Ti Laptop 约 12 GB 显存。P1–P4 的神经网络训练与可训练特征默认走 GPU；
模型和训练张量必须显式检查 CUDA 设备，不允许静默退回 CPU。

原版 CPU 环境继续用于构图、采样及数值参考。预处理全面迁移 GPU 是另外的工程优化，
不以其完成与否判断论文科学结果是否复现。若迁移 PCA、近邻、局部 SVD 或采样，
需单独核验图、符号/坐标约定及采样序列，避免同时改变协议和后端。

一次运行一个种子或一个会话。当前 Achilles 三种子总运行约 189 秒、峰值分配约 937 MiB，
不能据此推算二阶或扩散任务。每类新任务先跑一个完整配置，记录准备、谱分解、训练和解码
分别耗时、峰值显存、CPU 内存与产物大小，再估算批量成本。
超时和资源上限由该试运行确定后写入批量配置，不预先承诺整篇训练时长。

拟保存：配置与哈希、逐轮损失、最佳/最后检查点、实际学习率、谱/积分告警、
显存、退出状态和阶段日志。批量任务支持逐会话续跑，训练续跑需包含优化器、调度器和 RNG 状态；
遇到非有限值、输入哈希变化、缺失梯度或 CUDA 不可用时明确终止并记录原因。
这些批量与监控能力是后续实现要求，不是当前入口已经全部具备的功能。

## 6. 数值核验与统计分析

按用户要求，发现对齐偏差时先将具体输入、协议和原版输出保存为回归用例，
确认用例在修复前失败、修复后通过，再恢复完整实验。对齐测试使用固定版本的
原版结果、独立计算或数学不变量作为依据，不把 KAIR 自己的当前输出当作正确答案。
未解释的对齐失败阻止对应实验进入“已验证”状态。

| 层次 | 必须覆盖的对齐测试 | 主要发现的问题 |
| --- | --- | --- |
| 数据与协议 | 小型可追溯输入上的 bin 单位、计数、PCA 变换、标签及划分；导出参数与检查点一致 | 预处理和协议改变导致的指标差异 |
| 图与采样 | 邻接、核、节点偏移、重复采样贡献；条件图之间无意外连边 | 数值算子相同但输入图或采样不同 |
| 编码器 | dropout 掩码及位置、BN train/eval 状态、归一化、权重键与形状 | 3D 作者模型无法忠实加载或评估 |
| 学习过程 | 各阶特征、内积特征、损失、参数梯度与多步优化；扩散梯度有限差分 | 前向接近但训练方向或参数更新不同 |
| 解码与比较 | 试次/时间划分、kNN 距离及并列边界、指标单位、跨动物方向和样本对应 | 表征相同但报告指标不同 |
| 真实数据回归 | 保留 Achilles 已验证协议；每新增一种模型先通过一个真实数据配置 | 小型测试通过但真实流程漏掉关键步骤 |

对旋转不变的表征比较不变量或对齐后的几何，不要求任意潜空间坐标逐值一致。
跨设备随机数与 CUDA 稀疏浮点误差单独记录；只在有参考误差依据时设定容差，
不能因一次完整实验没达到论文分数就改变通过阈值。

- **实现核验**：固定图、初始化、采样和模式，比较算子输出、损失、梯度和若干步参数更新。
  现有一阶 SGD 对照使用 `rtol=2e-4, atol=2e-5`；新算子需按尺度和 CPU 参考误差
  事先登记容差，不直接沿用或事后放宽。扩散时间另做有限差分梯度核验。
- **随机算子**：dropout 用可核验的固定掩码比较算子行为，另检验实际随机路径；
  相同种子不保证 CPU 与 GPU 产生同一掩码。保留 CUDA 稀疏累加的非逐位确定性说明。
- **训练与选择**：所有登记种子均报告；最佳检查点只能用指定验证指标选择，
  不使用测试误差挑模型或预处理。对相同输入和协议给出逐种子差值及分布。
- **科学比较**：大鼠以动物、猕猴以会话作为主要实验单位；种子变异另报。
  12 个有向动物对共享动物，并非 12 个独立样本；连续时间点也不是独立重复。
  样本较少时保留个体值，任何置信区间说明重采样单位和依赖假设。
- **差异处置**：依次查数据/预处理、图与采样、算子、训练和评估定义；
  保留 notebook train 模式与冻结 BN 的 eval 模式两套结果。
  无法解释的效果差异继续标记未解决，不仅凭“随机性”判为通过。
